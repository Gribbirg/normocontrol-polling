# F5 Господина — поллинг нормоконтроля

Опрашивает Google-таблицу нормоконтроля и максимально быстро репортит изменения
в Telegram: кто, в каком столбце и что именно изменил. **Видит и цвет заливки**
(зелёная ячейка = успех — главный сигнал в этой таблице), и текст. К каждому
репорту прикладывается полный дамп таблицы (xlsx, с цветами). Пингует
ответственных по `@username`.

Данные тянутся как **xlsx-экспорт** того же публичного линка (`export?format=xlsx`)
— это единственный бесключевой способ получить цвета ячеек (CSV/gviz отдают только
текст). Парсинг — на чистой стандартной библиотеке, **API-ключ не нужен**.

Отслеживаются только первые 9 колонок основной таблицы (A…I); правый блок
«Антиплагиат» и прочее за её пределами игнорируются (`xlsx.MAX_TRACK_COL`).

Конфиг-driven: любое число подписок (группы и/или конкретные студенты → любой
чат → пинги любых людей). Менять подписки можно командами бота на лету.
Зависимостей нет — только стандартная библиотека Python 3.

## Структура

```
normocontrol-polling/
├── main.py              точка входа (python3 main.py <команда>)
├── src/                 исходники
│   ├── polling.py       цикл: два потока (таблица + команды), single-instance lock
│   ├── config.py        загрузка/сохранение конфига и атомарное состояние
│   ├── xlsx.py          загрузка xlsx из Google + разбор (текст + цвет заливки)
│   ├── diff.py          вычисление изменений (текст и цвет) и матчинг подписок
│   ├── telegram.py      клиент Telegram Bot API (urllib)
│   ├── report.py        формирование репорта и отправка с xlsx-дампом
│   └── commands.py      команды бота (whitelist чатов, правка подписок на лету)
├── config/
│   ├── config.example.json   шаблон
│   ├── config.json           реальный конфиг (в .gitignore)
│   └── state.json            снапшот таблицы (в .gitignore, создаётся автоматически)
└── README.md
```

## Хранение данных (переживает падения)

- `config/config.json` — настройки и подписки. Статичный файл, скрипт его **не трогает**
  (кроме правок командами бота).
- `config/state.json` — снапшот таблицы. Пишется **атомарно** (`tmp` + `os.replace`),
  поэтому падение во время записи не портит данные; при перезапуске состояние
  подхватывается с диска → дубли-уведомления не уходят.
- Пути переопределяются через env `CONFIG_PATH` / `STATE_PATH` (для деплоя с
  персистентным volume).

## Настройка

1. `cp config/config.example.json config/config.json` и заполнить.
2. Токен бота — в `config.json` (`bot_token`) или через env `TG_BOT_TOKEN`
   (env приоритетнее; для деплоя храните токен в env/секретах).

### Подписка

```jsonc
{
  "name": "ГРУППА-XX -> Целевой чат",
  "groups": ["ГРУППА-XX"],            // коды групп (матч по столбцу «Группа»)
  "students": [],                     // ИЛИ подстроки ФИО конкретных студентов
  "columns": [],                      // [] = все столбцы; иначе фильтр по названиям
  "chat_id": "-1001234567890",        // куда репортить
  "mentions": [                       // кого пинговать (приоритет — @username)
    { "name": "Имя Фамилия", "username": "@some_username", "id": 123456789 }
  ],
  "attach_dump": true                 // прикладывать ли xlsx-дамп
}
```

- `mentions` поддерживает: `"@username"`, число-id, или объект
  `{name, username, id}`. Пинг идёт по `@username` (надёжно уведомляет);
  `id` — запасной вариант, если ника нет.
- Подписка матчит изменение, если его группа в `groups` **или** ФИО содержит
  одну из `students`. Пусто и то и другое → следит за всем.

### Whitelist чатов (управление через бота)

- `listeners` — список `chat_id`, в которых бот реагирует на команды. Чаты вне
  списка **полностью игнорируются** (включая `/start`).
- `open_registration` (по умолчанию `false`): если `true`, новый чат может
  добавить себя в `listeners` командой `/start`.
- Команды доступны всем участникам разрешённого чата и правят `config.json` на
  лету — поток опроса подхватывает изменения (см. «Команды бота»).

### Команды бота

Привязаны к чату, где отправлены (каждый чат правит только свою подписку):

| Команда | Что делает |
|---|---|
| `/start` | Зарегистрировать чат как слушателя (если `open_registration`) + справка |
| `/help` | Справка по командам |
| `/watch <код\|ФИО>` | Следить за группой (`ГРУППА-01-23`) или студентом (по ФИО) |
| `/unwatch <код\|ФИО>` | Перестать следить за целью |
| `/ping <@user\|id>` | Пинговать при изменениях (приоритет — `@username`) |
| `/unping <@user\|id>` | Убрать пинг |
| `/list` | Что отслеживается в этом чате |
| `/stats` | Сводка: антиплагиат, нормоконтроль, допуск, примечания |
| `/status` | Статус поллинга |
| `/pwd` | Показать `chat_id` текущего чата |
| `/dump` | Прислать полный дамп таблицы сейчас (xlsx с цветами) |
| `/test` | Проверка связи |
| `/github` | Ссылка на исходный код |
| `/stop` | Убрать чат из слушателей |

## Запуск

```bash
python3 main.py init     # засеять состояние без уведомлений (первый запуск!)
python3 main.py test     # проверить доставку во все чаты подписок
python3 main.py run      # таблица + команды бота (основной режим)
python3 main.py once     # один проход опроса таблицы — для cron
python3 main.py bot      # только слушатель команд (без опроса таблицы)
```

> Первый раз обязательно `init` (или первый `run`/`once` сам засеет состояние
> без спама), иначе все текущие пометки прилетят как «новые».
>
> `run`/`bot` берут single-instance lock (`config/.f5gospodina.lock`): второй
> инстанс не стартует — иначе `getUpdates` конфликтуют (409) и бот тормозит.

## Деплой

### systemd (Linux) — основной способ

```ini
# /etc/systemd/system/f5-gospodina.service
[Unit]
Description=F5 Gospodina — normocontrol polling
After=network-online.target
Wants=network-online.target

[Service]
WorkingDirectory=/opt/normocontrol-polling
ExecStart=/usr/bin/python3 /opt/normocontrol-polling/main.py run
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

`Restart=always` = после краша поднимется и продолжит с того же места
(`state.json` персистентный). Токен и подписки берутся из `config/config.json`
(можно переопределить токен через env `TG_BOT_TOKEN`).

Развёртывание вручную:

```bash
git clone https://github.com/Gribbirg/normocontrol-polling.git /opt/normocontrol-polling
# положить config/config.json (с токеном) — он gitignored, в репозитории его нет
sudo systemctl enable --now f5-gospodina
journalctl -u f5-gospodina -f   # логи
```

### cron (каждую минуту) — альтернатива без долгого процесса

```cron
* * * * * cd /opt/normocontrol-polling && python3 main.py once >> /var/log/f5.log 2>&1
```

## Добавить бота в группу

Чтобы репортить в групповой чат (а не личку), добавьте своего бота
в группу и укажите её `chat_id` (для супергрупп вида
`-100…`). Узнать `chat_id`: отправить в чате команду `/pwd`, либо посмотреть
`getUpdates`, либо через MTProto-клиент.
